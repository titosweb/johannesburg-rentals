# 🏠 Johannesburg Rentals

> 🚧 **Project Status: In Progress**

Johannesburg Rentals is a property rental website currently under development. The website is designed to provide users with a simple and easy way to browse available rental properties in Johannesburg and express interest in a property.

## 📌 Mini Summary

The website allows potential tenants to browse rental properties, view basic property information and contact me when they are interested in a listing. When a client expresses interest, their enquiry is received through email so that I can follow up with them directly.

The project is currently being developed and additional features will be added as development continues.

## ✨ Current Functionality

- 🏠 Property rental listings
- 📍 Johannesburg-focused rental properties
- 🔎 Easy-to-understand property information
- 📧 Client enquiry/contact functionality
- 📩 Email notification when a client is interested
- 📱 User-friendly website layout
- 💻 Responsive design
- ⚡ JavaScript functionality
- 🧭 Simple website navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub

## 🎯 Project Objective

The goal of Johannesburg Rentals is to create a simple digital platform that connects people looking for rental properties with available listings.
